# 🌦 Weather Forecasting Dashboard

An interactive Streamlit-based data analytics and machine learning dashboard for weather data exploration and temperature prediction using Linear Regression.

---

## 🚀 Project Overview

This dashboard allows users to:

- Upload custom weather datasets (CSV)
- Perform Exploratory Data Analysis (EDA)
- Visualize distributions and correlations
- Train a Linear Regression model
- Evaluate model performance using R² and MSE
- Analyze feature importance
- Compare actual vs predicted values

Built with Python and deployed using Streamlit.

---

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Seaborn
- Matplotlib
- Scikit-learn

---

## 📊 Features

### 1️⃣ Data Overview
- Dataset preview
- Summary statistics
- Missing value detection

### 2️⃣ Visualization
- Distribution plots
- Correlation heatmap

### 3️⃣ Model Training
- Feature selection
- Linear Regression
- Train-test split (80-20)

### 4️⃣ Results & Insights
- Actual vs Predicted visualization
- Model performance metrics
- Feature coefficient analysis

---

## 🧠 Machine Learning Approach

- Missing values handled using mean imputation
- Supervised regression modeling
- Evaluation Metrics:
  - R² Score
  - Mean Squared Error (MSE)
